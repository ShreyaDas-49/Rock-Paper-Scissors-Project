# Rock-Paper-Scissors-Project
<p>A fully interactive Rock Paper Scissors game built with a focus on clean UI and efficient game logic. This project demonstrates core front-end development skills including DOM manipulation, state management, and user interaction handling.</p>

<h3>Overview </h3>
<p>This application allows users to play against a computer opponent with instant feedback, dynamic score tracking, and a smooth, intuitive interface. Designed as a hands-on project to strengthen JavaScript fundamentals while maintaining a polished user experience.</p>

<h3>Key Features</h3>
<ol>
<li>Interactive Gameplay: Real-time user vs computer selection with instant result display</li> 
<li>Dynamic Score Tracking: Tracks wins, losses, and ties across sessions</li> 
<li>State Management: Efficient handling of game state using JavaScript</li> 
<li>Reset Functionality: One-click score reset for a fresh game experience</li> 
<li>Minimal & Intuitive Design: Focused on usability and visual clarity</li>
</ol>

<h3>Tech Stack</h3>
<ol>
<li>HTML5 – Semantic structure</li>
<li>CSS3 – Styling, layout, and responsiveness</li>
<li>JavaScript (Vanilla) – Game logic, DOM manipulation, event handling</li>
</ol>

<h3>What I Learned</h3>
<ol>
<li>Implementing game logic and conditional flows</li>
<li>Managing UI updates dynamically using the DOM</li>
<li>Structuring clean, readable, and maintainable code</li>
<li>Usage of Local Storage</li>
</ol>
